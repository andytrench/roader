# Decisions

Choices the spec ([ROADWAY_MODEL_SPEC.md](ROADWAY_MODEL_SPEC.md)) leaves open, or where it
conflicts with this repository's own rules. Each entry names the requirement it touches.
Change an entry by adding a new one that supersedes it; do not edit history.

| ID | Date | Touches | Decision | Why |
|---|---|---|---|---|
| D-001 | 2026-11-22 | Section 1 | The spec governs scope: US limited-access highways, ramps, interchanges, grade separations, and crossing streets within 150 m. Street, sidewalk and rural-road goals in the old `AGENTS.md` and `docs/RND_PILOT.md` are dropped. | The spec lists local streets as a non-goal. |
| D-002 | 2026-11-22 | Repository rules | The pre-spec `roader area` command and its area config are retired; they depended on external local data paths. Other tools consume Roader through its export files. | `.cursor/rules/repo-hygiene.mdc`: the repository is self-contained. |
| D-003 | 2026-11-22 | AC-H1, FR-SV | val3dity runs as an external command from tests only. It is never imported or vendored. See `docs/THIRD_PARTY.md` for its license. | The spec names it as the independent oracle; `licenses.mdc` requires a recorded decision for copyleft tools. |
| D-004 | 2026-11-22 | Section 0 | The new pipeline is built beside the old one. The pre-spec modules live in `roader.legacy` and are deleted when milestone 1 passes. | The old code goes from samples to triangles with no stored model, so it cannot be extended into the spec's design. |
| D-005 | 2026-11-22 | Section 0 layout | The spec's sub-packages live under `src/roader/` (`roader.io`, `roader.model`, ...), not a top-level `rim/`. | `AGENTS.md` fixes `src/roader/`. |
| D-006 | 2026-11-22 | FR-RL-1, FR-RL-2 | The rule loader and a minimal data file land in milestone 1; the library is fully populated in milestone 3. Every value not confirmed against a published standard is marked `placeholder: true`. | FR-RL-1 forbids hard-coded conventions from the start; the spec schedules the full library for milestone 3. |
| D-007 | 2026-11-22 | FR-DM-5, FR-IN-2 | Working frame per unit: transverse Mercator on the GRS80 ellipsoid, centered on the unit (scale 1.0, no false origin), heights NAVD88 orthometric. The anchor longitude, latitude, the PROJ string and the geoid model name are stored in the model. | One documented right-handed 3D frame per tile; distortion under 1e-5 over a 10 km unit. |
| D-008 | 2026-11-22 | FR-IN-5, FR-IN-7 | Milestone 1 uses OpenStreetMap only, read from a pinned extract file in the fixtures cache, behind a per-source switch. TIGER is added as a second source in milestone 4. | Determinism (FR-PL-3) needs a pinned input; OSM is share-alike data, so it must be switchable. |
| D-009 | 2026-11-22 | FR-IN-6, section 11 | Imagery is behind a switch and off by default. | Spec section 11. |
| D-010 | 2026-11-22 | AC-H6, L8 | Provenance is recorded per model element. An element is split wherever its parameters would come from different sources, so every parameter inherits exactly one source tag from its element. | Keeps the schema readable while meeting "every parameter carries a source tag". |
| D-011 | 2026-11-22 | AC-H5, FR-PL-3 | The native model serializes to canonical JSON: sorted keys, no whitespace, floats rounded to 1e-6 m / 1e-9 rad and printed with `repr`. Ids are hashes of content (source feature ids, stations), never of input order. | Byte-identical reruns. |
| D-012 | 2026-11-22 | Section 0 process | Work runs in parallel lanes, one git worktree and branch per lane. The integrator owns `main` and the shared files (`pyproject.toml`, `docs/THIRD_PARTY.md`, `DECISIONS.md`, `src/roader/cli.py`). | Plan for the overhaul. |
| D-013 | 2026-11-22 | FR-RL-1 | Rules are keyed by road class, era and jurisdiction only. Other qualifiers (structure family, pavement material, rural or urban) go in the rule id, e.g. `clearance.vertical.rural`. Eras are `pre1970`, `1970_1994`, `1995_plus`. | Keeps lookup to three keys with deterministic most-specific resolution. |
| D-014 | 2026-11-22 | FR-RL-2 | `motorway` stands in for Interstate until a jurisdiction key separates them. Confirmed rows use the published minimum as `low` and `typical`; their `high` is only a plausibility bound. Default fill confidence is 0.3 for placeholder rules and 0.5 for confirmed ones. | Only the FHWA Interstate lane width and clearances are confirmed so far. |
| D-015 | 2026-11-22 | FR-DM-2 | CityJSON 2.0: `metadata.referenceSystem` is omitted because the unit frame has no OGC URL; the PROJ string and anchor go in `metadata.roaderFrame`. Road and earthwork shells are written as CompositeSurface with `closed_shell: true`, since Road objects cannot hold Solid geometry; bridge parts are Solids. | Keeps the file valid against the official 2.0 schema. |
| D-016 | 2026-11-22 | FR-DM-1 | OpenDRIVE: banking is written as roll and the crown as two linear shape records (second-order error, about 0.2% of crown height at 6%); lane widths are scaled to sum to the pavement width. Exact cross-section values travel in userData. | OpenDRIVE cannot express the L2 cross-section exactly; the lossless copy is the native model. |
| D-017 | 2026-11-22 | FR-EX-1 | A unit that fails any hard gate is written to `held/` with `HELD.json` and its `published/` copy is removed. Fallback to a coarser LOD waits for the LOD chain in milestone 2. | Never publish a failing unit. |
| D-018 | 2026-11-22 | AC-A1, AC-A2 | Holdout: 25 m blocks ranked by a salted sha256 of the block index; blocks are held out in rank order until 20% of occupied 1 m cells is reached. Fitting stages must exclude `holdout_mask`. | Deterministic, spatially blocked holdout so withheld points are not neighbours of fitted ones. |
| D-019 | 2026-11-22 | AC-H3 | Void rays start 0.05 m above the lower road surface and stop 0.01 m below the soffit (upper surface minus deck depth). Meshes of the lower road itself and its barriers are ignored. | Tests the opening, not the road's own pavement. |
| D-020 | 2026-11-22 | AC-H4 | Continuity tolerances: within a road 1 mm position, 1e-5 rad heading, 1e-5 grade; across links 1 cm and 0.1%. | Within-road joints are analytic; links join separately fitted roads. |
| D-021 | 2026-11-22 | FR-SV-7 | Conforming contact: no vertex of one solid lies on the other's touching face unless it coincides with one of that face's vertices. Differing diagonals are allowed. | Testable form of "conforming faces". |
| D-022 | 2026-11-22 | AC-H6 | A rule-sourced Provenance without `rule_id` fails AC-H6. Terrain meshes use `element_id="terrain"`. A hard gate that cannot run fails with `skipped_reason`. | Every rule fill must name its rule; a skipped gate is not a passed gate. |
| D-023 | 2026-11-22 | FR-IN-2, D-007 | A point file with no vertical CRS is taken as NAVD88 and recorded as "NAVD88 (assumed)"; a declared vertical datum other than NAVD88 is refused for now. WGS84- and NAD83-based horizontal inputs enter the unit frame with no datum shift (about 1 m absolute); they stay registered to each other because every source takes the same path. | 3DEP headers often omit the vertical CRS; the M1 tile matches the national NAVD88 DEM to about 0.3 m. |
| D-024 | 2026-11-22 | Section 9 pilot | M1 site is `wboylston_laurel_i190`: Laurel Street on one ~101 m bridge over I-190 (2+2 lanes, twin carriageways), West Boylston MA, lidar MA_CentralEastern_1_2021 at 22.5 pts/m². Pinned fixtures (sha256 in `tests/sites.yaml`) are the reference; a forced re-fetch produces new hashes. | Simple rural overpass, no ramps within 500 m, class 17 present. |
| D-025 | 2026-11-22 | FR-SG-4, FR-ST-4 | Skew convention: a support lies along s = station + tan(skew_rad)·u. Inside a structure, station lines are skewed to the supports and ramp back to square outside it. Deck ends take the skew of the nearest support. | Matches the synthetic scene; keeps deck, abutment and approach faces conforming. |
| D-026 | 2026-11-22 | FR-ST-3 | Until abutment fields exist, abutment thickness along the road is `Support.cap_width_m`, and the block is anchored at the deck end rather than at `Support.station`. | No dedicated abutment geometry in the M1 schema. |
| D-027 | 2026-11-22 | AC-H6, D-010 | A mesh built from several model parameters takes the least-trusted source among them (rule < vector < inventory < measured) until `Road` carries its own provenance. | Never overstate confidence in a rendered part. |
| D-028 | 2026-11-22 | FR-SG-2 | Chord tolerance 10 mm on drivable surfaces and pavement edges; station spacing capped at 10 m to avoid long thin triangles. | Keeps surfaces accurate and triangles well shaped within the budget. |
| D-029 | 2026-11-22 | Section 1 M1 scope | M1 generates fill slopes only. Cut and wall side slopes, non-bridge structures and barriers off the pavement or deck are deferred; the generator raises rather than emitting a partial solid. | The M1 site is on fill; failing loudly beats an invalid solid. |
| D-030 | 2026-11-22 | FR-AF-4 | Soft-prior penalties for radius, K and grade are scaled by the violated bound, not by the rule's range width. | Wide ranges (e.g. radius 500–100000 m) would otherwise make the penalty vanish. |
| D-031 | 2026-11-22 | FR-VC-4, FR-ST-2 | Structure ends: the surface-sheet break is measured 1.5–4 m beyond each pavement edge (a drop of more than 2.5 m) and corrected per side by offset·tan(skew). Deck-class (ASPRS 17) extents are used when they agree with the sheet break within 5 m. | Sheet breaks alone run long over wingwalls; class 17 is not always present. |
| D-032 | 2026-11-22 | AC-A1, AC-A3, D-018 | The holdout is drawn from evidence-labelled pavement. AC-A3 reference edges are measured on all points but scored only inside held-out blocks. | Scores accuracy on surfaces the model claims to represent, without fitting to the scored samples. |
| D-033 | 2026-11-22 | FR-OC-2, FR-XS-3 | Under-deck clearance is checked against the rural rule; when it fails, only a rule-filled deck depth may be refitted and measured values are never changed to pass. Lane counts are inferred by rule in M1. | Measurement outranks rules; a failed clearance is flagged, not hidden. |
| D-034 | 2026-11-22 | AC-H6, FR-ST-3 | `Road.prov` (optional) carries a road's whole-road source and fit statistics; when set, it is the source of the road's pavement and earthwork meshes, superseding D-027 for that road. `Support.thickness_m` (optional) sets abutment thickness along the road, superseding D-026 when set. Both default to None so earlier model files load unchanged. | Requested by the solids and validate lanes; keeps old models readable. |
| D-035 | 2026-11-22 | FR-SG-3, AC-H4, FR-AF-3 | L6 schema for milestone 2: `JunctionArea` gains `kind` (gore, merge, diverge, intersection), `seams` (`JunctionSeam`: road, station, offset range) and `holes`; its surface is lifted from the adjoining roads so elevation and slope match at every seam. `Link` gains optional seam stations `from_s`/`to_s` (mid-road diverges and merges) and `prov`. Median kinds stay as in `Median` (FR-XS-4). All default-valued. | Gives the junctions, fit and validate lanes one shared contract before wave 2. |
| D-036 | 2026-11-22 | Section 9 sites, milestone 2 | M2 cloverleaf site is `woburn_i93_i95` (I-93 over I-95, Woburn/Reading/Stoneham MA) on MA_CentralEastern_1_2021, QL1, 15.9 pts/m², class 17 present. The AOI was corrected from the pre-spec pilot box (which missed the interchange) to cover all ramp ends plus Washington Street over I-95; West Street is out. Stack site shortlisted: I-635/US 75 High Five, Dallas (TX_Pecos_Dallas_B3_2018, QL2); runner-up Pregerson I-105/I-110, Los Angeles. | Full cloverleaf with good density and deck classes; stack chosen for coverage and class 17. |
| D-037 | 2026-11-22 | AC-H2, FR-CR-1 | A crossing in a site's reference list is any plan intersection of two in-scope edges without a shared node where at least one edge is limited-access. Reference lists and structure ends are drafted from data and stay `needs human review` until a person confirms them; OSM bridge extents are never used as AC-A5 references (they disagree with deck returns by 7–32 m at Woburn). | Keeps references independent of the model and of unreliable tags. |
| D-038 | 2026-11-22 | FR-SV-7 real-time profile | Embed depth is the smallest separation distance over candidate directions (normals of mutually crossing faces), measured by ray exit distance from embedded vertices and face centroids; only closed solids are measured, terrain is checked for coplanar overlap only; "coplanar" means within 0.1 mm. Reported as gate `AC-H1:realtime`. | The spec defines the 0.2 m minimum but not how to measure it. |
| D-039 | 2026-11-22 | AC-P2, AC-P3, AC-P4, AC-H4, FR-AS-1 | A width or slope change over less than 1 m, or abutting lane groups with different lane widths, is a step (AC-P2). Budgets: four-lane km = length × lanes / 4, freeway triangles exclude its own deck footprints; an overpass counts the structure, its supports and the carried road's barriers on the span; met when the median actual/budget ≤ 1, any asset over 3× is a defect (AC-P3). UV stretch is per triangle from the uv0-to-3D map; uv0 must use distance along the offset line, since centre-line station stretches by u/R (10% at 50 m radius) (AC-P4, FR-AS-4). Mainline curvature continuity within 1e-6 /m (AC-H4). LOD deck top within the level's chord tolerance plus 1 mm; a structure proxy (`part == "proxy"`) is allowed only at LOD 3 (FR-AS-1). | Measurable definitions for targets the spec states qualitatively. |
| D-040 | 2026-11-22 | FR-OC-3, AC-H6 | Terrain completion (stage 8): a 2 m grid from ground-class returns; ground under decks and under roads out to the embankment toe is removed and refilled by interpolation; nodes under pavement, decks and caps are lowered below those bodies, footings re-seated below the finished terrain. `TerrainPatch.fill` records each node's origin: 0 measured, 1 gap interpolated, 2 under a structure, 3 under a road or embankment, 4 lowered below a solid. | Ground under structures is reconstructed, never draped, and its origin stays auditable. |
| D-041 | 2026-11-22 | L4, D-029 | In M1, cuts, walls and fills gentler than 1.5× the flattest rule fill are written as side-slope kind `none`; the measured kind and ratio are kept in flags. Adjacent runs with similar ratios are merged. | The generator renders fills only (D-029); sub-mm toe steps between near-equal runs made slivers. |
| D-042 | 2026-11-22 | AC-A1 | Over a bridge, the carried road's plan footprint for point assignment is the full deck outline with a 1 m tolerance, so deck returns are scored against the deck and ground seen past the deck edge is not. | Deck-edge returns were being scored against the road 7 m below. |
| D-043 | 2026-11-22 | AC-H5, D-011 | `run_pipeline` returns the model in its serialized (rounded) form, and alignments are built from already-rounded values, so the in-memory model, the saved model and every export agree exactly. | Rounding on save moved spiral joints by up to 7 mm and broke determinism across the save boundary. |
| D-044 | 2026-11-22 | AC-A5, AC-H2 | Site reference lists use one layout: `crossings[*].structure` names a structure, and `structure_ends: {status, structures: [{id, carries, over, ends: [{along, start_lonlat, end_lonlat, length_m}]}]}`. Until a person labels the ends, AC-A5 runs against draft class-17 ends and is a consistency check only, since the pipeline also uses class 17. | One reader for every site; honest about what the M1 AC-A5 number proves. |
| D-045 | 2026-11-22 | FR-RH-1, AC-H6, D-034 | The pipeline sets `Road.prov` to the source covering the most length over the road's alignment and profile elements, with length-weighted confidence, the measured share as `observed_fraction`, and the longest rule element's `rule_id` when the source is rule. Hidden parameters such as the rule-filled pavement thickness keep their own provenance in the model but no longer color the whole road body. | Under D-027 every real-site road rendered as rule because of its thickness alone. |
| D-046 | 2026-11-22 | FR-SG-3, AC-H4, L6, D-035 | Junction areas come from diverge/merge links, from a road end lying on another road at grade (within 1 m in plan and height), and from three or more road ends meeting. Each participant's interval grows from the node until its section clears the others by 1 m, plus 1 m, up to 200 m; the outline is the union of their pavements with gore pockets of at most 6 m closed straight. `JunctionSeam` stores its road's lifted surface at the seam (plan point, heading, curvature, z, grade and rate, cross slopes and rates, thickness, side); `JunctionArea.sections` stores lifted interior sections every 5 m. `surface_z` is a 1/d³ inverse-distance blend of these patches with lateral overshoot weighted ×4. Solids drop the covered road cells and build a slab (plus fill over terrain) sharing the road grid vertices at each seam. Areas within 30 m of a carried structure or touching a support are skipped and flagged. All new fields default-valued. | The surface is a function of the stored model alone, and seams match each road exactly in value and slope. |
| D-047 | 2026-11-22 | FR-SV-7 real-time profile, D-038 | Real-time solids are generated, not post-processed: pavement, embankments and barriers embed 0.25 m into what carries them; abutments and caps rise 0.25 m into the deck, columns 0.25 m into the cap; deck top and soffit are unchanged. Plan outlines are inset 0.2 mm (supports, embankments), 0.4 mm (pavement, deck) or 0.6 mm (barriers, parapets) so analytic contact faces end up apart; end-to-end neighbours get 0.4–0.8 mm gaps instead of embedding. | The spec gives the 0.2 m minimum but not the construction; shared walls would z-fight. |
| D-048 | 2026-11-22 | FR-AS-3, FR-AS-4, FR-AS-5, AC-P4 | `Mesh.normals`, `uv0`, `uv1` may be per vertex or per face corner; generated solids use per-corner values. `uv0` on road and deck tops is distance along the offset line by arc length across, with a new UV segment every 0.25 rad of turning; walls use (distance along outline, z); other faces an isometric face projection; terrain has no `uv0`. `uv1` is shelf-packed per mesh at 1024 px with 2 px padding. Normals are smoothed only across model-continuous edges. | Per-vertex UVs on closed solids make zero-area UV triangles; centre-line station stretches by u/R. |
| D-049 | 2026-11-22 | FR-AS-1, D-028 | Every LOD level is a complete rendering at chord 1 cm, 5 cm, 25 cm and 1 m; station spacing cap is 10 m × √(tol / 1 cm), superseding D-028 above level 0. Structure spans keep 1 cm at every level so decks and voids survive. No proxy is generated. glTF uses `MSFT_lod`, USD a `lod` variant set; CityJSON and the native model carry level 0. | Watertight levels with voids intact, inside the budgets. |
| D-050 | 2026-11-22 | FR-AF-3, AC-H4 | Joint fit: components are roads joined by links or crossings; only components with a seam are re-solved. PVI stations and curve lengths stay fixed; elevation and along-road surface slope are equal at each seam and every crossing keeps its recorded `dz_m`. The child's cross slope is held at the parent's surface slope for 5 m, then returns to its own over 20 m. A seam (then a clearance) that worsens a road by more than 5 cm RMS is dropped and flagged; a component with nothing left to drop is reverted. | Never force data to fit a constraint; every drop is visible. |
| D-051 | 2026-11-22 | FR-AF-3, L0 | Links come from the input vectors: a road end within 2 m of another road's line, parent ranked mainline > ramp/connector > street. A child's end is pinned to the parent's reference line, and to its heading and curvature when within 25°. A child end off the parent's pavement gets `FR-AF-3:no_seam` and no link. | Topology is in the vectors; a ramp crossing a crowned parent at an angle cannot meet D-020 otherwise. |
| D-052 | 2026-11-22 | FR-CR-1 | Linked roads meeting in plan with less than 1 m height difference are their junction overlap, not a crossing. | Removes false grade separations at gores. |
| D-053 | 2026-11-22 | FR-VC-3 | A registered centerline more than 6 m from the input vector is bridged from its neighbours and its measured centers there are ignored; the bridged line is a 0.3-weight hint where no measured center is left. | Registration was wandering onto neighbouring pavements at Woburn. |
| D-054 | 2026-11-22 | FR-XS-4 | Median classification every 10 m between the inner edges, against the line joining the edge heights: barrier (linear returns within 3 m of an edge, any median under 12 m with a rise over 0.5 m), none (gap under 0.5 m), depressed (ground over 0.25 m below the line), raised (over 0.10 m above, under 12 m wide), painted (flush, spread ≤ 5 cm); flush but rough or unpaved and at least 12 m wide is depressed and flagged. Runs are smoothed by a 5-station majority, minimum 30 m. | Measurable thresholds for the FR-XS-4 kinds. |
| D-055 | 2026-11-22 | FR-XS-4, L0 | A two-way mainline drawn over a divided section is split into twin one-way roads, ids `stable_id("rd", seed, "right"/"left")`, flagged `FR-XS-4:split`. | Twin carriageways need independent profiles. |
| D-056 | 2026-11-22 | D-011, AC-H4 | L2 element stations are rounded on construction, so a model read back has no station gaps. | 1e-6 m station gaps failed AC-H4 at Woburn. |
| D-057 | 2026-11-22 | Section 9 sites, D-036 | Stack site `dallas_high_five_i635_us75` (I-635/US 75 High Five) is fetched and pinned on TX_Pecos_Dallas_B3_2018 (QL2, 7.5 pts/m², 45.6 M returns, class 17 present). The AOI was widened from the shortlist box, which covered levels 3 and up only, to hold both gores of all eight general-purpose direct connectors; TEXpress connector far ends, Midpark Road and Coit Road are outside. | D-058 | 2026-11-22 | FR-VC-5 | An unmatched-sheet candidate is a paved component not covered by any fitted road footprint (plus a 3 m pad and 15 m past each end, within 1 m in height), at least 400 one-metre cells, at least 40 m long and 3–24 m wide. It is flagged with its outline WKT, never added as a road. Thresholds are provisional pending real-data tuning (54 candidates at Woburn). | Report what the vectors miss without inventing roads. |
| D-059 | 2026-11-22 | FR-CR-1 | Crossings come from input-vector intersections excluding shared nodes (within 1.05 m); each is located on the fitted lines within 30 m or flagged `FR-CR-1:not_located`. | Topology from the vectors; location from the fit. |
| D-060 | 2026-11-22 | FR-CR-3, FR-VC-4 | Structure runs on one road are chained into one structure unless the road rejoins ground between them (at least 5 m of observed stations with no side drop deeper than 2.5 m); the merged extent takes the less trusted method. Extents are clamped to the carried road's ends and flagged `FR-VC-4:clipped`. Side drops and class-17 deck runs ignore returns more than 1.5 m above the road surface. | One deck carrying a road over several ways is one structure; stacked decks must not hide the deck below. |
| D-061 | 2026-11-22 | FR-OC-1, D-010 | Occluded intervals get completion records with a bound of edge RMS plus the worst disagreement of the two one-sided extrapolations, plus 1%/m when only one side is observed; flags `FR-OC-1:completed`, `:uncertain` (bound over 0.25 m) or `:unbounded`. | D-062 | 2026-11-22 | FR-ST-3 | On spans longer than `structure.even_span` high, piers are spaced evenly and kept out of crossed clear zones, flagged `FR-ST-3:even_spacing`. The rule is a placeholder last resort. | Long viaducts need supports when none are observed. |
